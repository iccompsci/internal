This project used two different methods for calculating climate instability. Given daily temperature readings for a year: ● Method 1 used the DP segmented least squares algorithm to fit the appropriate amount of line segments to the data for a given cost per line segment

This project is an attempt to quantify the growing instability of climate. We focus on temperature readings from cities [1] throughout the continental US and explore ways to assess the growing variability as a function of time. This instability was then overlaid with tornado data in an attempt to find a correlation.

● Method 2 counted the change in the sign of the slope of the readings. For example, for a single week, if temperature readings were: 65→67→70→54→60→62→63 The week would have an “instability count” of 2 because of the change from 70 to 54 (increasing to decreasing) and the change from 54 to 60 (decreasing to increasing)

Given a set of N points (temperature readings), we want to fit some number of line segments in order to maximize accuracy but minimize the cost and error of fit. Given that the best possible solution to minimize error would be N-1 segments, a cost is associated with creating a segment to avoid this outcome.

19

In order to calculate a time proxy for climate instability, we wanted to utilize a dynamic programming implementation of the Segmented Least Squares Problem [2].

A general visualization of the process it took to calculate an instability for a region (Instability came from the slope of a regression line which was computed on the number of line segments needed per year to fit daily temperature readings).

A top down implementation recursively considers and finds an optimal segment for all subproblems. For example, given a computed segment for points i - N, the subproblem would be considering a segment for points 1 - (i-1).

For each location with readings, the above methods calculated instability. This process was done for the every year in the data, and then, a regression line was fit to the instabilities. The slope of that line served as the overall quantifier for the change in stability in that location over the 24 years used from the dataset.

To begin, the algorithm computes the error of fitting an optimal segment for each point to every other point. These resulting segments are cached to avoid unnecessary recursive calls. The algorithm then checks all calculated segments and all of the possible subproblems that arise from choosing that segment while keeping track of the optimal solution (the one that minimizes cost and error). When the algorithm finishes running it returns that optimal solution.
