IC Bacteria Tracker Bradley Keith ’19, Computer Science

John Barr, Professor, Computer Science Summer 2018 This project was supported in part by the Dana Internship Program of Ithaca College. Purpose

Method

This project provides a mobile application to guide and aid in the sampling of bacteria around the Ithaca College campus for students in the biology department. The application will guide students to desired sample locations and allow them to enter information about the samples they take for future identification and testing.

This mobile application was developed using the ReactNative framework for JavaScript along with several APIs including Google Maps and React Navigation. The entire user interface of the application was built using JavaScript with PHP used to connect to a MySQL database to store samples and fetch user information. Live previews and testing of the app was accomplished using the Expo mobile application and Expo’s create-react-native-app program

Summary The goal of this project was to create a cross-platform (iOS and Android) app and web-based database that would enable the collection of bacteria across the Ithaca College campus. The project used the React Native framework and involved the investigation and evaluation of numerous APIs and platforms including libraries for in-App navigation, maps, databases, and GIS functions. Based on these evaluations, the current working application was constructed by integrating the most robust and powerful packages into React Native components to produce the final code.

Future Work Future goals for this project include: • Finalize information details • Create a more permanent and robust database • Prepare and release the app to both the IOS and Android mobile stores. • Generalize and expand the app for use by other colleges by enabling them to customize the user, sample, and location information.

The Bacteria tracker app consists of four main screens: • Login: students login using their Netpass username • Main Menu: after login, main navigation to the other screens • Viewer: a heatmap showing the location and density of bacteria found around campus • Tracker: a map guiding students to locations where samples are needed and allowing them to select locations to enter sample information These four main screens are accompanied by an assortment of forms and confirmation pages for entering sample information. These pages also include a help screen to ensure students know how to take the physical samples.
