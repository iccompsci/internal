Unified Election Database for US Federal Elections from 2016 to 2020 Emmett Barry & Ali Erkan There is not one single database which holds multiple US federal elections. The data is spread out and cannot be queried to find specific information when needed. We have been working to solve this issue and have created a database that allows you to easily access election data for federal elections between 2016 to 2020

The data for this project was pulled from multiple Harvard election datasets, MIT datasets, and datasets that were found on Github. In the future we hope to continue to add more data and perform statistical analysis to try to predict future election winners.

This is a choropleth map of the total votes in each US county for all federal elections between 2016-2020. See how evenly distributed voting is when considering multiple elections

Database schema of the tables we needed to convey the data. In total there are 9 tables and 8 million data entries counting 977 million federal election votes in the U.S.

This is a choropleth map of counties in the United States where the counties in blue voted republican and the counties in red voted democrat for all 8 federal elections between 2016 and 2020. The counties in grey are counties that flipped between republican and democrat during the elections. This map gives us a better view of which areas in the US are swing areas and which areas are consistent.

This is a section of the sql query that was used to get the data for the map graph to the left. This query finds which party had the most votes for each specific election so we can see which counties flip between republican and democrat for federal elections. While the query is complex, because of our work building this database it was much easier to access this data than it would’ve been if we were working with the raw election datasets.
