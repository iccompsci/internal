Machine Learning Minor

The Machine Learning minor introduces students to computational methods that find patterns in data and use them to make predictions or classify information. Students interested in artificial intelligence can use the minor to explore how models are developed, evaluated, and applied to problems in other fields.

Why This Minor?

For computer science majors, the minor offers a focused way to study machine learning within the broader field of computing. Students learn to think about the data, algorithms, and evaluation methods behind systems that learn from examples.

For students in other majors, machine learning can add a useful approach to questions involving patterns or predictions. Understanding how these models are built and tested helps students assess their results rather than simply accept an answer from a tool.

Interdisciplinary Connections

In Applied Physics, machine learning could help identify patterns in measurements from experiments or computational models. Physics students might use data-driven models to study physical phenomena that are difficult to analyze directly.

Students in the Physics-Engineering 3-2 program could explore predictive models built from engineering measurements. In Business Analytics, prediction and classification techniques can complement other ways of studying business data.

Course Descriptions

Foundations of CS I

This course is an introduction to solving problems by writing code. Course content includes the design, development, testing, and analyzing of python code. Also included are basic coding structures that are present across many programing languages, such as statements, loops, and functions.

Foundations of CS II

This course reinforces and extends the skills learned in "Foundations of CS I". It introduces object-oriented programming, functional programming, and basic algorithmic analysis. End-of-semester projects make use of APIs and libraries to access real-world data-sets and explore how programs can be useful to other disciplines or areas of interest.

Machine Learning

This course explores supervised learning (including linear/logistic regression, decision trees, and neural networks) and unsupervised learning (including clustering, anomaly detection). It covers both theoretical concepts and practical applications of machine learning. It provides opportunities to implement and experiment with these algorithms on real-world data sets.

Topics in Machine Learning

This course explores topics in deep neural network learning such as natural perception tasks (e.g., image recognition, audio classification), as well as emerging topics related to recommendation systems and large language models.
